## 🧠 Overview

OptiScaler is a Windows gaming utility that acts as a middleware layer between supported games and modern image-scaling technologies. It can redirect compatible upscaler inputs toward alternative backends, giving players additional control over technologies such as DLSS, FSR, and XeSS. The project also includes configurable frame-generation functionality, rendering adjustments, sharpening controls, and an in-game overlay for managing supported options.

## 🚀 Key Features

| Feature                | Description                                                                    |
| ---------------------- | ------------------------------------------------------------------------------ |
| 🔄 Upscaler Switching  | Redirect compatible game upscaling to different supported technologies.        |
| 🎯 DLSS Support        | Provides configurable DLSS-related options for compatible titles and hardware. |
| 🔷 AMD FSR             | Supports multiple FSR generations where the game and rendering API allow it.   |
| 🔵 Intel XeSS          | Adds XeSS processing options to supported configurations.                      |
| ⚡ Frame Generation     | Provides frame-generation capabilities through supported implementations.      |
| 🖥️ Vulkan Support     | Offers compatibility with selected Vulkan-based rendering configurations.      |
| 🎮 DirectX Support     | Works with supported DirectX 11 and DirectX 12 game configurations.            |
| 🛠️ Image Tweaks       | Includes sharpening, scaling, ratio, and related visual adjustments.           |
| 📊 Performance Overlay | Displays configurable performance information while playing.                   |
| 🎛️ In-Game Controls   | Provides an overlay for changing supported OptiScaler settings.                |

## Additional Information for Windows Users

OptiScaler works at the game rendering layer, so compatibility can differ between individual titles, engines, APIs, and graphics configurations. Some technologies require particular GPU generations or additional game-specific adjustments. Users should review compatibility information before applying advanced options, and modifications involving online games may interact with anti-cheat systems.
